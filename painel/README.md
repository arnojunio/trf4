# Painel de Nomeações – TRF4 (Edital 01/2025)

```sh
npm install      # use `npx npm@11 install` se o npm 10 der erro "edgesOut"
npm run dev      # http://localhost:5173
npm run test:unit
npm run build    # gera dist/ (site estático)
```

**Atualizar os dados:** substitua `public/data.txt` pelo texto copiado do site do TRF4
(mesmo formato). Em dev basta recarregar a página; em produção, copie o novo arquivo para `dist/`.
